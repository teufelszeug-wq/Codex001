# 統合小説制作システム

更新：2026-09-20。目標は既存3作品の共用化にとどまらず、過去の制作システム案を整理統合し、新シリーズの企画から保存まで利用できる制作環境を作ること。

## 工程

資料取込・出典監査 → ジャンルと企画 → 世界・言語・人物 → シリーズ／巻／章／シーン構成 → 制作会議 → 初稿 → 読解レビュー・検査 → 改稿・承認 → 保存・引継ぎ。

## 会議

ソクラテス役は前提・定義・反例、マキャヴェッリ役は利害・権限・実行可能性、ケインズ役は制度・資源配分・不確実性を検討。編集者と整合性担当が検証する。歴史上の本人の発言ではなく思考視点として使用する。

会議の発行と意見回収・結論保存を実装。全担当の返答、作品ID、基準版を確認し、未回答や別作品の応答を拒否する。結論は提案扱い。本文の執筆停止は解除しない。会話内の単独AIによる役別レビューと、独立プロセスによる実行を区別する。

## 今回追加した操作

```text
node writing-system/cli.mjs init . new-series "新シリーズの仮タイトル"
node writing-system/cli.mjs council amelia "統合システムの設計レビュー"
node writing-system/cli.mjs finish-council amelia 会議ID system/返答.json
node --test writing-system/test.mjs writing-system/project.test.mjs writing-system/health.test.mjs writing-system/changes.test.mjs writing-system/transactions.test.mjs
```

新シリーズ作成は空の設定・資料台帳・原稿・画像・会議の領域を作る。他作品の設定はコピーしない。同じ作品IDが存在する場合は上書きしない。途中で作成に失敗したフォルダは調査用に残す。
