# 作品設定と執筆運用 v2.0

## 中核

作品名は『聖女の加護は筋肉から』を作業上の主題として使用。英語副題 Blessings through Discipline は旧候補として保存。

アメリア・リュミエール、17歳。銀髪ストレートロング、紫瞳。修行前は華奢寄り、後にしなやかな筋肉がつく。身長約161cmは復元報告由来の暫定値。体格の成長は経過時間、食事、睡眠、労働に連動させる。

優しい、真面目、努力家、自責しやすい、政治的駆け引きには弱い。弱さを隠す努力と、本人が気づいていない負けず嫌いが共存する。困っている人を助ける選択は、従順さだけで説明しない。

婚約者を本当に好きだった。礼儀・歴史・ダンスを学んだのは責務と恋心の両方から。婚約破棄で失うのは立場だけでなく、会いたい相手と具体的に思い描いた未来。冤罪を推理する前に失恋する時間を与える。

大聖堂は幼少期からの家、教育と施療と礼拝の場所。すべての聖職者を悪人にしない。食事、友人、仕事、日常の親切があったから、排除が痛い。

## 語りと口調

- 三人称・アメリアに寄った限定視点を標準にする。他人の思考は表情・所作・発言から推測する。
- 日常は柔らかい自然な敬語。公式は習得した高度な敬語。限界時の崩れを演出として使うが、常時噛ませない。
- シリアス7：コメディ3は全体の方向。裁定、失恋、野営の恐怖に無理な笑いを挿入しない。
- 師匠登場まで筋肉ギャグを封印。師匠の実用的な体格を出会いの驚きにする。
- 「まだ立っていられる」は婚約破棄の山場の言葉として温存し、毎場面の口癖にしない。
- 光、呼吸、手の震えを連発しない。必要な場面では具体的な行為・対話に置き換える。
- 世界の情報は行動に必要な順に出す。全カード項目を毎場面に列挙しない。

## 信仰・加護

正統教義は祈り、善行、節度、感謝、慈善。鍛錬を加護の条件とする教義はない。身体と加護の安定の関係は、後にアメリアが比較・失敗・観察を重ねて発見する。

女神固有名、原語聖句、加護の数式、光紋の機能は保留。現段階で神託による無罪判定、嘘発見、瞬時の証拠解析は追加しない。聖女の能力と聖堂から与えられた職務資格は分ける。追放は能力を消去しない。

## 作中ノートと制作側の記憶を分ける

作中：施療ノートは観察と施療の記録。個人的な日記と将来の成長記録は別の役割を持つ。ノートを奪われても本人の記憶まで消さないが、記憶だけでは公的な立証にならない。

制作側：次の3層を state.json 内に置く。

1. Master Chronicle：場面、時系列、物証の所在、確定度。
2. Emotional Trajectory Map：その時点での感情、きっかけ、残る傷、次の場面への持ち越し。
3. Literary Signature Log：文体方針、問題があった実例、修正規則。

## レビュー役（独立した実在人格や回収済みの内部記憶ではない）

| 役 | 引き継ぐ観点 | 変更できないこと |
|---|---|---|
| アメリア役 | 17歳の体感、恋心、自責、助けたい意思、本人が知る事実 | 犯人の秘密を先取りしない。主人公の嫌悪だけで事件を撤回しない |
| 作家役 | 情景・行為・対話にして書く、山場を作る | 旧設定を説明なく上書きしない |
| 編集役 | 読者の理解、繰り返し、情報量、長編の起伏 | 字数のためだけの水増しを要求しない |
| 構成役 | 因果、事件の時系列、場面の役割 | 既存場面を未執筆へ戻して消さない |
| 心理・感情役 | 全人物の感情継続、回復の段階 | 失恋直後を即座に爽快な復讐へ変えない |
| 世界・地図役 | 場所、歩行、権限、生活費、職務 | 未設定の距離・人口を既知として補わない |
| 派閥・陰謀役 | 利害、誰が何を知るか、証拠と回収 | 全員を共犯にしない。便利な万能黒幕を作らない |
| 整合役 | 口調、年齢、衣装、宗教、他作品の混入 | 未確認の名前や呪文を復元扱いしない |
| 校閲役 | 視点、主語、重複、誤字、動作の連続 | 心理の自然さを単語数だけで判定しない |
| ビジュアル役 | 年齢、銀髪・紫瞳、体格、衣装、光粒 | 未取得画像を採用画像と呼ばない |
| 夢記憶役 | 過去に経験した記憶・夢・連想の再使用 | 夢に未提示の真相や新しい幼少期事件を潜ませない |

ユーザーに呼ばれたときはアメリア役として会議用の台詞を出してよい。作中本人の記憶と、制作側が知る結末を必ず分ける。通常はレビュー結果だけ簡潔に出す。

## 一場面ごとの手順

1. 出典と状態を読む。今回の作業案を決め、変更IDを付ける。
2. 場所・開始時点・人物の知識・目標・障害・終点を記録する。
3. 作家／構成／心理／世界／陰謀／整合の観点で短い判断を残す。
4. 本文を場面ID付きで保存する。
5. 本文に実際に出た事実をカードへ追加し、「予定」と区別する。
6. 人物の知識と所持品、証拠、感情、移動を更新する。
7. 禁止語チェックと読解レビュー。修正後に同じ箇所を確認する。
8. 次の再開位置と未回収事項を保存する。

## カード共通仕様

ID／種類／表示名／状態／出典または変更ID／初出場面／本文で示した事実／作者だけが知る計画／未確定項目／関連IDを保持する。

対象：人物、NPC、宗教、聖句、加護、技能、修行、筋肉・身体成長、食材、レシピ、場所、建物、店舗、政府・王家・組織、動植物、魔物、武器、衣装、画像。

場所は世界→大陸→国→領地→地方→都市→地区→通り→建物→部屋の階層を基本とする。City→Area→Node→POI は都市内の表現として併用する。未設定項目は空値にし、面積や人口を自動で捏造しない。今回の審理室だけは本文に必要な相対配置を作業案として登録。

料理が登場したら食材と料理カードを作る。実用レシピの分量・加熱は料理資料で確認し、未検証ならその旨を記す。今回の新規本文に食事は登場しないため、新しい料理カードは不要。

画像はキャラクター／背景／文字／エフェクトを分離する方針。光粒は場面に応じて調整。画像ID・元ファイル・衣装時点・生成指示・採否・修正履歴を紐付ける。現在は画像ファイル未取得、採用画像登録0件。

## 保留と禁止

他シリーズ固有設定、扇、7つ数える演出、隔離された具体呪文、灰の都などテスト用地名は本文へ入れない。隔離語を資料内で説明することは可能。

二重婚約案は履歴に残し、現行本文へ復活させない。名前や女神表記は中立の呼称で進められる限り執筆を止めない。重要な変更は作業案として記録し、ユーザー採用済みと偽らない。
