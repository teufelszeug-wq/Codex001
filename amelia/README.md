# アメリアシリーズ 制作室

再構築日：2026-09-14／版：2.0

## 現在の状態

シリーズの軸は、聖女アメリアが失恋と冤罪による追放を経て、労働・修行・人助けの中で自分の人生を取り戻す成長物語。政治ミステリーは、この人生を壊した仕組みと責任を解き明かす筋として組み込む。

このフォルダは今回新しく作った制作資料。過去の非公開DBやAIの記憶を回収したものではない。出典は添付された5資料。元の添付と sources/ は変更しない。

## 読む順序

1. `01_資料監査と変遷.md`：実際に確認できた記録、旧稿と改稿の違い、訂正事項。
2. `02_作品設定と執筆運用.md`：人物・世界・各レビュー役・記録更新の手順。
3. `03_追放事件ファイル.md`：今回の統合改稿用の事件設計。読者向けでないネタバレ資料。
4. `04_章構成と進捗.md`：長編化の計画と本文の所在。
5. `manuscript/C01-S06_裁定室の午前.md`：今回書いた統合改稿の新規本文。
6. `state.json`：人物・場所・証拠・場面・感情・変更履歴の現在値。
7. `05_レビューと再開メモ.md`：今回のチェック結果と次の作業。

## 状態の区分

- 継承：提供資料内で反復された設定、または明示的な採用・廃止の記録がある方針。
- 旧正式：過去の会話で正式版とされた本文。後の改稿案があっても履歴を消さない。
- 旧初稿：原文が確認できるが最終稿とはしない。
- 要約のみ：作成された記録はあるが本文のファイルが未取得。
- 今回の作業案：今回の執筆に用いる新しい設計。過去の確定設定と混同しない。
- 保留／隔離：不一致、根拠不足、他作品混入の疑いがあるもの。

## 運用

執筆前に設定・現在地点・人物の知識を読む。執筆後に state.json と章進捗、レビュー記録を更新する。「登録した」「記憶した」という会話だけで完了扱いにしない。

本システムはファイルを使う執筆手順とレビュー役の構成である。バックグラウンドの自律AI、モデルの再学習、過去チャットの自動取得は実装していない。「自己成長」は修正点を明文化し次稿へ反映することを指す。

`& ./amelia/check_manuscript.ps1` で禁止語・未整理プレースホルダー・文字数・本文ファイルと状態記録の対応を確認できる。人物心理、因果関係、文章の良し悪しは人の読解を要するため、機械チェックの合格だけで完成とはしない。

各章最低10万字、標準15万〜20万字は制作目標として継承する。今回の成果はシステム再構築と新規1場面であり、第1章完成ではない。
