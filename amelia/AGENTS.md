# アメリアシリーズ専用の作業範囲

このルールは `amelia/` 以下だけに適用する。Codex001には別作品・別作業が共存する。リポジトリ全体をアメリア専用と見なさない。

- アメリアの設定、原稿、会議、状態、検査結果はすべて `amelia/` 以下に保存する。
- 本文は `manuscript/`、会議と運用実績は `meetings/`、人物・世界・感情の現在値は `state.json`。
- リポジトリ直下のREADME、ゲーム開発ファイル、developブランチをアメリア作業で編集・移動・削除しない。
- 他作品から人物、地名、呪文、設定、AI役の記憶を取り込まない。参照したい場合は出典と採否を明記する。
- コミット前に変更対象がすべて `amelia/` で始まることを確認する。リポジトリ全体をまとめてステージしない。
- 会議→決定→執筆→状態更新→検査→GitHub保存→Notion保存→読み戻し確認の順で進める。
- 「会議」はレビュー役ごとの観点を記録するもの。独立エージェントを実行していない場合は、複数AIが実行したと称さない。
- 毎回 `README.md`、`02_作品設定と執筆運用.md`、`state.json`、最新会議、直前本文を読む。
- 原文がない過去ログや画像を復元済みと扱わない。初稿はユーザー承認済み設定と区別する。
- 実行確認：`& ./amelia/check_manuscript.ps1`。結果を保存し、心理・因果・時系列は別途読解レビューする。
- 執筆中にユーザーが新たな指定をした場合は、設定変更と理由を記録して反映する。
