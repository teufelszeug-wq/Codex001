# PRISM M-T0〜M-T6 — verifiable roundtable gate

This PR contains a portable audit and regression tests. The full locally executable bundle also includes 12 template eligibility contracts, five authored topic meetings, timestamp-signature checks, 100-yen settlement, specialist research coverage matrix, and vertical HTML newspaper prototype.

## Rules
1. Match race metadata/official roster, then introduce the race and the course before the first horse.
2. Diagnose every horse in number order, saying number and name together, and follow with counterarguments and editorial summary.
3. Missing workout/video/weather/odds must stay unknown. Machine lint is not a human naturalness review.
4. Nineteen characters played by one model are never nineteen independent AI calls.
5. Observed market odds must be separate from editorial estimates; 100 yen per ticket settlement.
