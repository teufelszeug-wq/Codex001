## Layout decisions
1. An original Japanese racing newspaper, not a copied competitor masthead or newspaper page.
2. A3 portrait, 4-page editorial experiment: cover / detailed horse-column / editorial comparative analysis / five-topic editorial agenda.
3. 3-tier typographic hierarchy: masthead and main headline / secondary article headings / dense serif body. Use black, off-white, spot vermilion, and grounded JRA frame colors.
4. Japanese newspaper vertical body: top-to-bottom columns advance right-to-left. Horizontal Latin brand, small numeric fields and metadata only as intentional exceptions.
5. Main cover must have an unequivocal feature headline and dense 12-horse racecard, not a grid of unrelated cards.
6. Columns must separate frame number, horse number, name, jockey, carried weight, mutable odds (marked reference only), and verified career data.
7. Comparison page must focus on analysis and interpretation, not duplicate all racecard cells.
8. Roundtable printed last; no invented dialogue, character claim, pick, odds, video analysis or external model execution.
9. The 5-topic editorial agenda is NOT a recorded roundtable. Final marks or 100-yen tickets must not be filled in from guessed model outputs.
10. QA: four pages A3 verified with PDF renderer; verify all horse names, frame numbers, legibility, no text overlap, reading flow, and visual image originals; reject horizontal-dominant content pages.
