必要環境: Python 3.10以降、解析時lxml、実行時Linux libseccomp。
既存v0.9.12を別途展開したROOTから:

```bash
python3 scripts/build_january_research_dataset.py ROOT OUTPUT_DATASET
python3 scripts/run_b0_research.py --january OUTPUT_DATASET/january.json --bootstrap OUTPUT_DATASET/bootstrap.json --out NEW_RUN_DIRECTORY
```
