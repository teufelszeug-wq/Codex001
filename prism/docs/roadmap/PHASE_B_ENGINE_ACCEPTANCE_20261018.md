## 2担当の独立レビューと修正

予想・データ担当は、情報漏洩、確率、精算、再現性を再現検査。
編集・要件担当は正本との対応と過剰な完了宣言を点検。これらは開発レビューであり、予想家AIの競馬訓練実績ではない。

1. PR #3の未認識結果フィールドを許可リストで遮断。`results`、`win_payouts`、未知項目は拒否。
2. 公開時刻不明でも、固定時刻以後に発生したと分かる過去走は拒否。
3. 極端温度で下位馬を等確率へ丸めない。未対応の温度は入口で拒否、PL分母は残存重みの直接和を使用。
4. 精算をrace_id/prediction_hash/plan_hashに結び、券の重複・購入額不一致・返還/払戻競合を拒否。
5. barrier_noと当初のbarrier_countを固定。取消だけで他馬の位置効果が変わらない。
6. UTC offsetの異なる履歴も実時刻で直近3走を選択。

## モデルと安全境界

- 実験係数は固定の仮説。未検証の精度をTrue Probabilityの確定値と呼ばない。
- RAWとは構造化観測。Webスクレイパ・公式API自動取得の完成ではない。
- 入力hashは整合性だけを確認し、外部のsource/timestampの真正性を証明しない。
- PRE_AVAILABLEと歴史再構成は別mode。未知時刻を前時点へ偽装しない。
- 欠損モジュールはUNAVAILABLE。能力のcold-startだけ明示したpriorを使う。
- ばんえいは水分増加→軽馬場の向きを保持し、平地のpace/sectionalを流用しない。障害も別route。
- N-Value照合は本線と同じ履歴を確率へ再加算しない。市場処理は予想固定後。
- 5ペース別PL順位混合に校正後1着周辺確率を適用し、条件付き順位形状を保持。物理シミュレーションではない。
- Monte Carloの標準誤差/entropyは予測精度の信頼区間ではない。
- 候補選択は上限24候補・最大6点の制限集合内で期待収益合計を最大化。リスク最小化/Kelly最適/全券種全組合せの大域最適ではない。
- プログラムによる投票・資金移動・自動配備はしない。
