# M2 — World Builder Alpha

## Objective

Make the first real author-facing Golden Path operational:

**Genre → Setup Mode → World DNA → Review → Persisted Project**

The author retains control. Presets and recommendations are suggestions, not hidden defaults that become Canon.

## Design-review meeting

### Socratic review
"Choice" must include the ability to remain undecided. M2 therefore includes **ジャンル未定**, multiple genres, custom genres, and does not require a primary genre.

### Strategy review
The differentiator is not a long preset list; it is persistent world configuration that later drives Bible and Lint. M2 stores a structured profile rather than merely displaying a wizard.

### Systems review
A single giant form would become unmaintainable. World DNA is stored as stable section keys with per-section AUTO / MANUAL / SKIP modes. M2.5 can deepen Language/Culture without redesigning M2.

### Guest — UX architect / narrative tools designer
Long setup flows lose users if progress disappears. M2 therefore adds local wizard draft recovery. Recommendations are visible and editable, never silent automation.

## Scope implemented

- Catalog endpoint so web UI does not own the canonical genre/setup list.
- Initial genre catalog: Isekai, Noble Lady, Palace, Romcom, Mystery, SF, Fantasy, Romance, Contemporary, Horror, Historical, Adventure, Undecided.
- Custom genre names and weights.
- No mandatory primary genre.
- Setup modes: Quick, Guided, Full, Blank, Import.
- World DNA sections: Geography, Society, Economy, Technology, Magic, Religion, Calendar, Language, Culture.
- AUTO / MANUAL / SKIP per section.
- Free notes per section.
- Import-format intent capture without unsafe file parsing.
- Deterministic section-priority recommendations derived from genre weights.
- LocalStorage wizard recovery.
- SQLite persistence and ChangeLog.
- Project overview page showing the saved World Builder profile.

## Safety / authorship rule

AUTO means "the system may propose a candidate later." It does **not** mean "auto-commit to Canon."

No M2 action turns generated content into Canon.

## Deferred to M2.5

Detailed Language DNA, phonology, naming grammar, scripts, loanword policy, etymology, culture-contact modeling, and Earth-Origin replacement foundations.

## Deferred beyond M2

Actual DOCX/EPUB parsing is intentionally not implemented in M2. Import mode records format and intent only. Safe parsing, provenance, candidate extraction and author approval must be introduced together rather than allowing imported content to become Canon implicitly.
